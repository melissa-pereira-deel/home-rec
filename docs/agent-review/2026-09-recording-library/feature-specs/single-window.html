One place, no extra window.

Browsing keeps your search, page and scroll position. A recording stays active across pages. Naming opens inside the same 450 × 450 frame.

Interactive HTML study, not the native app. Audio, files and timing are simulated. The Recorder uses images rendered from the unchanged native views on a flat reference backing; native glass, focus and capture continuity still need implementation tests.

Lazy cards live in a bounded 60-record data page. Previous / Next moves through data pages, independently of how many cards fit on screen. This demo follows that model with synthetic records.
